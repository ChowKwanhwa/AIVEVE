## 正文

一个AI Social Feed方向的产品。

一个人 + Claude 跑了几个月,产品方向 / 文案 / 品牌视觉 / 完整设计 token / 一整套 build prompt 都已经到位 —— **就差一个能独立把整个东西做出来的人**。

---

### 急招

**全能开发 1 名**,短期合作起步(1–2 个月),做得舒服可长期。可远程,不卡时区。

**这不是纯前端枪手** —— 要求能交互一个美观漂亮的交互式落地页，然后产出一个基本能体验的AI Social Feed产品（不需要完美，让用户能体验到就行）

---

### 你要做什么

**第 1–2 周** — 落地一版**高质量 landing page**。
栈是 Next.js 16 + React + Tailwind + Framer Motion + GSAP / Lenis。视频背景 + liquid-glass UI + 6 个 section,有视觉锚点和滚动叙事。设计稿 / 文案 / 视觉 token / 完整 build prompt 全在 wiki 里,你只管落代码 —— **重点是好看 + 互动顺 + 上去想多停一会儿**。这是入场题,直接决定要不要继续。

**之后** — 把产品 V1 自己 ship 出来。
栈大概是 Next.js + Supabase + Drizzle + 一些 AI API(图 / 视频 / 文本生成类)。需要你能从 Figma / spec 一直 own 到上线 —— 数据模型、API 路由、异步任务 / 队列、文件存储、部署、监控,出 bug 自己 debug,需求自己拆。
**产品本身不需要做得多牛逼** —— 核心是能让用户上去玩、能体验核心玩法,不追求企业级架构,但要能跑、不崩、看得过去。

---

### 你大概要会

**必备**
- **Vibe Coding能力** —— 我们有figma设计规范，你可以全程Vibe Coding，只要出品质量过关就行；
- **全栈能力**:前端(Next.js / React / TypeScript / Tailwind)+ 后端(Node / API routes / Supabase / SQL 基础)+ 部署(Vercel / Cloudflare 类)
- **高动效 / 互动 landing**(Framer Motion + GSAP scroll-driven 必须熟练)
- **审美在线** —— 能区分 Linear / Vercel / Stripe 这种和淘宝模板
- **能独立 ship** —— bug 自己 debug,需求自己拆,不会被卡半天等回复
- 会用 AI 协作工具(Claude Code / Cursor 类)

**加分**
- 接过 OpenAI / fal.ai / Replicate 这类 AI API,懂异步任务 / 队列 / webhook
- 用过 Drizzle / Prisma ORM
- 做过 Three.js / R3F / WebGL hero 区
- 整过完整一个独立产品(自己设计 + 自己写 + 自己上线那种)
- 有自己的 portfolio 站


---

### 我提供

- **Claude Code Pro 账号**(或 Max,看体量),AI 协作权限开满
- 所有云服务 API:Supabase、Vercel、Cloudflare R2、fal.ai 等都到位,你直接用
- 完整的产品 / 设计 / 文案 / 视觉规范 wiki,你不用猜需求
- 按里程碑结算(landing 1 个 milestone,产品 V1 几个),金额我们聊
- 后续做得舒服 → 长期合作;不舒服 → 1-2 个月按交付走人,不留尾巴

---

### 不适合的人

- 不会读 spec,要拉着手讲细节的
- **审美一般,做不出 landing 视觉差异感的**(硬指标)
- **只会前端不会后端,或只会后端不会前端,或不能独立把一个东西完整 ship 出来的**(本职位是全栈,不是 token 工)
- 抗拒用 AI 编程工具,坚持手撸的(我们整个 workflow 是 AI-native)
- 一周回我两条消息的

---

### 怎么联系

私信我,或者评论留个微信(可以用马甲号),发我:

1. 一两个你做过的 **高动效 landing** 或 **scroll 互动项目**(URL 就行)
2. **一个你独立 ship 过的完整产品**(任何方向,看一气呵成的能力)
3. 你常用的栈 / AI 工具
4. 你大概什么时间能开始

**3 天内决定**,适合的当周开干。
