# Aivive — Brand Designer 招聘需求

> 本文件是发给候选设计师的 JD。内容基于 [[aivive-design]] v0.1(已定色板 / 字体 / 调性)与 [[relaunch-plan]](ASAP 节奏)。

---

## 一、项目背景

**Aivive(AVV)** 是一个基于 Solana 的 **AI + 社交**项目,由资深 Web3 孵化团队负责全栈孵化(品牌、产品、白皮书、官网)。

- **核心叙事**:AI + Give(分享价值)/ AI + Vive(鲜活的 AI)——双关
- **上所路径**:MEXC(老代币已上)→ **KuCoin(目标,ASAP)**→ Bitget
- **法律实体**:YU Network SRL(哥斯达黎加)
- **阶段**:品牌完全重做(不沿用前身项目)

我们不是从 0 提案品牌方向。我们已经有一份 13 节的 **DESIGN.md 设计系统 v0.1**(色板、字体、spacing、motion、组件规范全部定值),招你来是**按现有 brief 高质量落地**,不是参与品牌策略。

---

## 二、你将交付

### 必交付

1. **Logo 体系**
   - 正版(完整)+ 简版(icon)+ 单色版
   - 矢量源文件(AI / SVG)+ 多格式导出(PNG @1x/2x/3x、ICO、favicon)
   - 最小可用尺寸与净空规范

2. **品牌 VI 手册**(PDF / Figma 双版本)
   - 色板(基于 DESIGN.md 固定值)
   - 字体规范(基于 Geist + IBM Plex Serif)
   - Logo 使用规范(正确用法 / 错误用法)
   - 组件视觉示例

3. **社媒模板**
   - Twitter / X:封面 + 头像 + 推文图(3 套尺寸)
   - Telegram:群封面 + 置顶图
   - Medium / YouTube(如开设):频道视觉

4. **一图读懂**
   - Tokenomics 可视化(分配饼图 + vesting 时间轴)
   - 项目定位图(AI × 社交 × Web3 交叉)
   - 上所里程碑图

5. **海报**
   - 上所公告海报(KuCoin / BG)
   - 里程碑海报
   - 通用营销海报(空投、活动、AMA)

6. **白皮书视觉**
   - 封面
   - 关键章节插图(与白皮书文本配合,约 6–10 张)
   - Tokenomics 图表视觉

7. **官网视觉稿**
   - 首页(Hero + 3–5 个 section)
   - 2–3 个子页(产品 / Tokenomics / About)
   - 深色模式主稿 + 浅色模式文档页

### 加分交付

- **Motion 资产**:Logo 呼吸动画(Lottie / MP4)、Hero flow 动画
- **Dapp UI 扩展**(如能从官网延伸到产品 UI)
- **3D 资产**(Spline / Blender 源文件)

---

## 三、核心能力要求

1. **能读 DESIGN.md 直接落地**。我们的 brief 是 markdown,你按 token 值产出,对应关系清晰。不擅长读设计规范文档的不合适。
2. **3 年以上资深品牌设计经验**,作品集需有**完整品牌体系落地**(不是单张 Logo 试作)
3. **Figma 精通**(主交付工具);Illustrator / After Effects 加分
4. **深色模式直觉好**。Dapp 和官网主界面深色 + 渐变 + 发光粒子,你的作品集里应该有类似调性
5. **3D / glass morphism / 有机几何** 相关作品是必备。扁平矢量和线条插画风格的**不匹配**
6. **Motion 意识**。核心视觉 signature 是 Breathe(2.8s 呼吸循环),你至少能给出 motion-ready 的静态稿结构

---

## 四、加分项(任一加分)

- 做过 **Solana / Web3 项目**(审美和社区节奏都要懂)
- 做过 **AI 产品** 周边视觉(Claude / ChatGPT / Midjourney 等)
- **中英双语**(中文涉及品牌命名与社区物料,英文是交易所对接语言)
- **独立推进能力强**(孵化方 ASAP 节奏,需要你自己判断边界)
- **3D 插图能力**(Spline / Blender)
- **Lottie 动效能力**
- 能把 DESIGN.md token 翻译成 **Tailwind config**

## 五、我们不看重

- Dribbble / Behance 粉丝数
- 大厂履历(小团队单兵作战能力更重要)
- 是否科班

## 六、视觉调性(作品集自筛)

从 [[aivive-design]] 抽取,方便你判断是否匹配:

- **调性三词**:**Alive / Warm / Sharp**
- **主色**:紫 `#5B3BEE` + 暖粉 `#FF8A5C` + 电光青 `#4FFFD8`
- **字体**:Geist(Sans 主体)+ IBM Plex Serif(仅用于 Give / Vive / Aivive 关键词)
- **插图风**:3D 玻璃态 orbs + 发光粒子 + 渐变网格 + 抽象曲面
- **Signature motion**:Breathe(呼吸)/ Flow(流动)/ Give(粒子飞行)

**禁区**(作品集里大量出现这些的,直接 pass 掉):

- ❌ 任何**红色**为主的品牌(我们要与前身项目做视觉切断)
- ❌ 纯黑 + 企业蓝(Stripe / Coinbase 风,劝退社区)
- ❌ **扁平矢量 / 线条插画**
- ❌ **机器人 / 电路板 / 神经网络** 套路(AI 陈词滥调)
- ❌ **emoji / 贴纸 / meme** 风格
- ❌ 任何**马**的意象

## 七、交付节奏

上所目标 KuCoin,项目方要求 **ASAP**。

| Week | 交付 |
|---|---|
| Week 1 | Logo 定稿 + 品牌 VI v1 |
| Week 2 | 社媒模板 + 一图读懂 + 白皮书封面 |
| Week 3 | 官网视觉稿(深色首页 + 子页) |
| Week 4 | Motion 资产 + 全量修订 |

时间紧,**交付快优先,过度打磨不加分**。不接受"我需要两周思考方向"的节奏 —— 方向已经在 DESIGN.md 里定好了。

## 九、如何申请

发给我:

1. **作品集链接**(网址 / PDF 均可,**不要 Dribbble 小图拼图**)
2. **3 个你觉得与 Aivive 调性最接近的作品**(在作品集里标出来即可)
3. **期望报价**(全职月薪 / 项目一口价 / 时薪均可)
4. **可开始时间**
5. **一句话**:为什么你认为自己匹配 Aivive

### 秒刷硬条件(满足任一直接 pass)

- 作品集里完全没有 Web3 / AI / 发光视觉 / 有机几何
- 只有 Logo 单品,没有成体系品牌落地
- 本周内无法开工
- 明显是学生 / 初级水平作品集
