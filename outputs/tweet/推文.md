## 1. V1 推文 28 条 · 6 类

### A. AI 深度观点(8 条 — 身份证明,质量 > 数量)

```
A1 — 「harness eats the model」(★ 核心爆款候选):

the harness eats the model.

same Claude, different scaffolding, outputs differ by 2x.

Cursor ≠ Claude Code ≠ Cline ≠ raw API.

if you're not picking the harness deliberately,
you're not picking anything.
```

```
A2:

"AGI is just bigger models" has been wrong every quarter
for two years.

"AGI is just better harnesses" is directionally right
but doesn't ship.

the truth is boring: scale + scaffolding + taste,
in that order, all needed.
```

```
A3:

the most underrated AI engineering skill in 2026:

deciding what NOT to put in the context window.

token bloat = bad outputs. minimalism is alpha.
```

```
A4:

agents don't fail at reasoning. they fail at:

1. retrieving the right thing
2. knowing when to stop
3. recognizing they're stuck

three failure modes. one cluster of fixes
(memory + termination + self-eval).
```

```
A5:

generation is solved.
taste isn't.

we have models that produce any image.
we don't have ones that know *which* image to produce.

that's the actual frontier.
```

```
A6:

a thing I keep noticing:

models from Anthropic, OpenAI, Google
converge on the same outputs for ~80% of prompts.

differentiation lives in the 20%.
that 20% is mostly harness.
```

```
A7:

the four interfaces AI products converge to:

1. chat
2. canvas (Figma-style)
3. notebook (Jupyter-style)
4. feed

#4 is the most underbuilt and the most interesting.
```

```
A8:

hot take: in 2026, prompt engineering matters less
than UI.

what your tool *makes you want to try* >
what your prompt extracts.

taste lives in the UX, not the model.
```

## 3. Thread 模板 3 条(每周发 1 条 thread,流量杠杆)

### Thread T1 — "harness eats the model"(★ 首选)

```
1/

most people who say "I use Claude every day"
actually use one of:

- Claude Code (Anthropic's harness)
- Cursor (Anysphere's harness)
- Cline (open-source harness)
- raw API (no harness)

same model. four very different products.

🧵
```

```
2/

a harness wraps a model with:

- tool design (which functions can it call?)
- memory (what does it remember between turns?)
- loops (when does it stop?)
- hooks (what fires when?)
- plan mode (does it pause to think?)

these are the actual UX of AI in 2026.
```

```
3/

the model is becoming the cheap part.

GPT-5 / Claude Opus 5 / Gemini 3 are within 80% of each other on most tasks. the differentiation is the harness.

if your only AI moat is "we use [latest model]",
you don't have a moat.
```

```
4/

we keep thinking about this for our own product.

the model decides what's *possible*.
the harness decides what's *useful*.

if you're building anything with AI,
spend more time on the second.

(more soon. ↻)
```

### Thread T2 — "AI 生成 != AI 工具"

```
1/

generation is solved.

flux, gpt-image, imagen — all produce any image
you can describe, at quality that was unimaginable
2 years ago.

so why are AI image products still bad?

🧵
```

```
2/

three answers, none of them about the model:

1. UI doesn't make you want to try
2. no memory of what you've made before
3. zero social context — you can't see what
   anyone else with similar taste is doing
```

```
3/

these are not model problems.
they're product problems.

solving them takes:
- a feed (not a chat)
- a remix flow (one click, no friction)
- a way to discover taste (curation, not search)
```

```
4/

if you've used Pinterest you know what we mean.

the pinboard wasn't a model breakthrough.
it was a UI breakthrough that turned image
discovery into a habit.

AI generation is missing its Pinterest moment.
```

```
5/

we've been thinking about this every day for a while.

soon. ↻
```

### Thread T3 — "60 天里学到的 5 件事"(W2 末发)

```
1/

day 14 of 60.
five things I've learned shipping an AI product:

🧵
```

```
2/

1) the design tokens > the design.

decide your colors / fonts / spacing on day 1.
write them in one file.
never look back.

we lost a week last year arguing palette.
this year we wrote 8 colors, moved on.
```

```
3/

2) the harness is the whole product.

we spent more time on auth + ledger + queue than
on prompt engineering. and the prompts work fine.

the boring infrastructure is the moat.
```

```
4/

3) "build vs buy" gets weird with AI.

we built: design system, ledger, social layer.
we bought: image gen (fal.ai), auth (Privy), DB (Supabase),
queue (Inngest), bridge (Wormhole CCTP).

if you're building any of the bought ones, why?
```

```
5/

4) AI products converge on the same 4 surfaces:
chat, canvas, notebook, feed.

we're betting on feed.
all four exist in 2026.
the feed is the most underbuilt.
```

```
6/

5) the only metric that matters in week 2 is
"does it boot."

not perf. not coverage. not lighthouse score.

`pnpm dev` works → green.
anything else is procrastination.

```
7/
