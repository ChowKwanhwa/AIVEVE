## C. 3-paragraph full pitch(对方回了之后回复用)

### C1 — VC full pitch(★ 核心)

```
The product

Aivive is an AI image-generation social feed launching summer 2026 on
Solana. Form factor: Civitai/Pixiv (visual feed + remix + creator profile),
not the chatbox AI image tools currently shipping. Thesis: the model layer
is solved (FLUX, gpt-image, Imagen all produce any image you can describe);
the product layer is broken (no taste discovery, no remix friction, no
social context). The right shape for AI image generation is a feed.

The token

AVV is the platform's deflationary anchor. Total supply 10B; initial
circulating 1B (10%); FDV $20-30M at TGE; 0.002-0.003 USDT initial price.
Tokenomics: Team 10% / Liquidity 18% / MM 5% / Ecosystem 30% / Airdrop
25% / Treasury 10% / Advisors 2%. Utility: all platform revenue is
collected in USDC on Base, then weekly cron bridges via Circle CCTP to
Solana, swaps to AVV via Jupiter, and burns via SPL Token burn.
Verifiable on Solscan. CertiK audited. Listing path: KuCoin first,
Bitget second.

Execution + ask

Team: 2 humans + Claude harness. Velocity: full Next.js 16 stack
scaffolded in W1, mainnet AVV + CertiK submitted W3, Base + Solana
multisigs deployed W2 (Safe + Squads), first buyback-burn cycle W5.
Same team previously shipped RH on MEXC (2026-03), so "will they ship"
is settled. Looking for: [seed allocation / advisor / KOL intro /
co-marketing]. Happy to share Dune dashboard target metrics + a
15-min walkthrough.

— [Your name]
```
