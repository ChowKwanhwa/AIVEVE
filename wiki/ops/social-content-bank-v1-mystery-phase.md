### A. AI 深度观点(8 条 — 身份证明,质量大于数量)

```
A1 — 「harness eats the model」:

the harness eats the model.

same Claude, different scaffolding, outputs differ by 2x.

Cursor ≠ Claude Code ≠ Cline ≠ raw API.

if you're not picking the harness deliberately,
you're not picking anything.
```

```
A2:

"AGI is just bigger models" has been wrong every quarter
for two years.

"AGI is just better harnesses" is directionally right
but doesn't ship.

the truth is boring: scale + scaffolding + taste,
in that order, all needed.
```

```
A3:

the most underrated AI engineering skill in 2026:

deciding what NOT to put in the context window.

token bloat = bad outputs. minimalism is alpha.
```

```
A4:

agents don't fail at reasoning. they fail at:

1. retrieving the right thing
2. knowing when to stop
3. recognizing they're stuck

three failure modes. one cluster of fixes
(memory + termination + self-eval).
```

```
A5:

generation is solved.
taste isn't.

we have models that produce any image.
we don't have ones that know *which* image to produce.

that's the actual frontier.
```

```
A6:

a thing I keep noticing:

models from Anthropic, OpenAI, Google
converge on the same outputs for ~80% of prompts.

differentiation lives in the 20%.
that 20% is mostly harness.
```

```
A7:

the four interfaces AI products converge to:

1. chat
2. canvas (Figma-style)
3. notebook (Jupyter-style)
4. feed

#4 is the most underbuilt and the most interesting.
```

```
A8:

hot take: in 2026, prompt engineering matters less
than UI.

what your tool *makes you want to try* >
what your prompt extracts.

taste lives in the UX, not the model.
```

these are the actual UX of AI in 2026.

you don't have a moat.
```

```
4/

we keep thinking about this for our own product.

the model decides what's *possible*.
the harness decides what's *useful*.

if you're building anything with AI,
spend more time on the second.
