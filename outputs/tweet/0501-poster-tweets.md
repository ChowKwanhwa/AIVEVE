## 1. Memory(海报 1.png)

> 海报文案:"Multimodal" is the most overrated AI feature of 2026. "Memory" is the most underrated. We're betting on the second.

### V1 — 短锐立场（quote-bait）

```
Every AI lab in 2026 is racing to ship the next multimodal demo.

Nobody is racing to remember you.

That's the bet.
```

### V2 — 对照式（信息密度高）

```
Multimodal AI knows what's in the photo you just sent.
Memory AI knows why you sent it.

One impresses investors.
The other changes how you live with it.

We're building for the second.
```

### V3 — Cycle 时间轴（破圈到 AI 圈）

```
2023 was the race for parameters.
2024 was the race for context windows.
2025 was the race for multimodal.

2026 should be the race for memory — but most labs haven't caught up to it yet.

We have.
```

## 2. The Math(海报 2.png)

> 海报文案:The math is finished. The rest is patience.

### V1 — Calm confidence

```
Most of building this wasn't about cracking new ground.

It was about deciding what not to ship — then sitting on the fully-working version until the timing's right.

Patience is the part nobody writes blog posts about.
```

### V2 — Contrarian 节奏

```
In crypto we romanticize "ship early, ship often, ship in public."

We picked the opposite — finish the hard part quietly, then sit on it.

Patience is a moat almost no one's willing to pay for.
```

### V3 — Direct 声明

```
We're not racing.
We're not iterating in public.
We're not chasing the cycle.

The product is built.
We're waiting for the right moment to put it in your hands.
```

## 3. The Loop(海报 3.jpg)

> 海报文案:We built the loop. Now we wait for it to be needed.

### V1 — Confidence + 反 hype

```
Most products ship the loop and hope it works.

We built ours, stress-tested it, then turned it off.

When the market needs it, it's already running.
```

### V2 — 短锐

```
You can't fake a loop into existing.

You build it, you stress-test it, then you wait for the world to catch up.

Patience scales. Hype doesn't.
```

### V3 — 反"manufactured urgency"

```
Every other launch tries to manufacture urgency.

We did the opposite — built the loop, then stopped talking until it would actually mean something.

Ours doesn't need a countdown.
```

## 4. The Category(海报 4.png)

> 海报文案:What we're shipping isn't a feature. It's a category.

### V1 — 立场宣言

```
"What category does this fit into" is the wrong question.

If a new product fits cleanly into an existing category, it's incremental.

If it doesn't, it might be the start of a new one.

We're betting on the second.
```

### V2 — 短锐 contrarian

```
Every analyst wants to put us in a bucket.
Social? AI? Tooling? Identity?

The bucket doesn't exist yet.

That's the whole point.
```

### V3 — 类比框架

```
Twitter wasn't a "shorter blog."
Stripe wasn't a "better PayPal."
Notion wasn't a "fancier Word doc."

They were new categories that incumbents kept trying to compress into old ones.

You'll see.
```

## 6. The Question(海报 6.png)

> 海报文案:Where does your AI money go? Most products refuse to answer the question.

### V1 — 直接问句（最像 quote-bait）

```
You pay $20/month for ChatGPT.
You pay for Claude. For Gemini. For Midjourney.

Where does that money actually go?
What did it buy you besides a token allowance?

Most products won't answer. We will.
```

### V2 — 短锐 contrarian

```
Every AI subscription you pay for evaporates the moment you cancel.

You bought access. You didn't buy ownership.

That's the gap we're closing.
```

### V3 — 对比框架

```
Spotify tells you nothing about where your $11.99 goes.
ChatGPT tells you nothing about where your $20 goes.

If you're paying for AI in 2026, you should be able to ask the question.

We built the version where you get an answer.
```

### V1 — 设计哲学立场

```
You don't see the buttons we deleted.
The screens we cut.

That's the part we're proudest of.
```

```
Every product team says "less is more."
Almost none of them ship it.

What you'll get is what's left after we got brutal.
```

### V3 — Confidence

```
The reason this app feels light isn't that we built less.

The shipped surface is the survivor.
```

## 8. Taste(海报 8.png)

> 海报文案:Generation is solved. Distribution is solved. Taste is the unsolved one.

### V1 — 论点立场

```
Generating content is solved — every model can do it.
Distributing content is solved — every platform optimizes for it.

What's left? Knowing what's actually worth generating, and what's actually worth seeing.

That's where we're spending our cycles.
```

### V2 — 短锐 contrarian

```
The AI race for the last 3 years was about supply.

The next 3 years will be about discrimination — knowing what to make, what to keep, what to throw out.

Models can't do that for you yet. We're working on the part where they can.
```

### V3 — Direct

```
Anyone can generate.
Anyone can distribute.

Almost nobody can decide what's good — at scale, with consistency, in a way that holds up over time.

Taste is the unsolved problem.
```

## 9. One Button(海报 9.png)

> 海报文案:The best AI products have one button. The worst have many.

### V1 — 立场宣言

```
Look at the AI products you actually use every day.

How many primary buttons does each one have?

The good ones converge to one. The bad ones explode into menus.

We picked convergence.
```

### V2 — 反 feature creep

```
Every PM wants to add another button.
Every designer wants to add another menu.
Every roadmap wants more surface.

The PM who says "delete one" is the rarest hire in tech.

That's who we hired.
```

### V3 — 对比框架

```
Photoshop has hundreds of buttons. Midjourney has one prompt.
Salesforce has hundreds of fields. Linear has one input.

The future of AI products won't be the one with more knobs.

It'll be the one where the knob disappears.
```
