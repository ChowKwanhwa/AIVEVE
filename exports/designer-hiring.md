## 一、项目背景

**Aivive(AVV)** 是一个基于 Solana 的 **AI + 社交**项目,由资深 Web3 孵化团队负责全栈孵化(品牌、产品、白皮书、官网)。

- **核心叙事**:AI + Give(分享价值)/ AI + Vive(鲜活的 AI)—— 双关
- **上所路径**:MEXC(老代币已上)→ **KuCoin(目标,ASAP)** → Bitget
- **阶段**:品牌完全重做,不沿用前身项目

我们不是从 0 提案品牌方向。已有一份 13 节的 **DESIGN.md 设计系统 v0.1**(色板 / 字体 / 间距 / motion / 组件规范全部定值),招你来是**按现有 brief 高质量落地**,不是参与品牌策略。

## 二、你将交付

### 必交付

1. **Logo 体系**
   - 正版 + 简版(icon)+ 单色版
   - 矢量源文件(AI / SVG)+ 多格式导出(PNG @1x/2x/3x、ICO、favicon)
   - 最小可用尺寸与净空规范

2. **品牌 VI 手册**(PDF + Figma 双版本)
   - 色板、字体规范、Logo 使用规范、组件视觉示例

3. **社媒模板**
   - Twitter/X:封面 + 头像 + 推文图(3 套尺寸)
   - Telegram:群封面 + 置顶图
   - Medium / YouTube(如开设):频道视觉

4. **一图读懂**
   - Tokenomics 可视化(分配饼图 + vesting 时间轴)
   - 项目定位图(AI × 社交 × Web3 交叉)
   - 上所里程碑图

5. **海报**
   - 上所公告海报(KuCoin / BG)
   - 里程碑海报、AMA / 空投 / 活动通用海报

6. **白皮书视觉**
   - 封面 + 关键章节插图(与白皮书文本配合,约 6–10 张)
   - Tokenomics 图表视觉

7. **官网视觉稿**
   - 首页(Hero + 3–5 个 section)
   - 2–3 个子页(产品 / Tokenomics / About)
   - 深色模式主稿 + 浅色模式文档页

### 加分交付

- Logo 呼吸动画(Lottie / MP4)、Hero flow 动画
- Dapp UI 扩展
- 3D 资产(Spline / Blender 源文件)

## 三、核心能力要求

1. **能读 DESIGN.md 直接落地**。我们的 brief 是 markdown,你按 token 值产出。不擅长读设计规范文档的不合适。
2. **3 年以上资深品牌设计经验**,作品集需有**完整品牌体系落地**(不是单张 Logo 试作)
3. **Figma 精通**(主交付工具);Illustrator / After Effects 加分
4. **深色模式直觉好**。Dapp 和官网是深色 + 渐变 + 发光粒子,作品集应有类似调性
5. **3D / glass morphism / 有机几何** 相关作品必备。扁平矢量 + 线条插画风格**不匹配**
6. **Motion 意识**。核心视觉 signature 是 Breathe(2.8s 呼吸循环),静态稿要 motion-ready

## 六、视觉调性(作品集自筛)

- **调性三词**:**Alive / Warm / Sharp**
- **主色**:紫 `#5B3BEE` + 暖粉 `#FF8A5C` + 电光青 `#4FFFD8`
- **字体**:Geist(Sans 主体)+ IBM Plex Serif(仅用于 Give / Vive / Aivive 关键词)
- **插图风**:3D 玻璃态 orbs + 发光粒子 + 渐变网格 + 抽象曲面
- **Signature motion**:Breathe(呼吸)/ Flow(流动)/ Give(粒子飞行)

### 禁区(作品集大量出现直接 pass)

- ❌ 任何**红色**为主的品牌(要与前身项目做视觉切断)
- ❌ 纯黑 + 企业蓝(Stripe / Coinbase 风,劝退社区)
- ❌ **扁平矢量 / 线条插画**
- ❌ **机器人 / 电路板 / 神经网络** 套路(AI 陈词滥调)
- ❌ **emoji / 贴纸 / meme** 风格
- ❌ 任何**马**的意象

如果作品集全是扁平 / 极简线条 / 纯企业感,这个岗位不适合。
